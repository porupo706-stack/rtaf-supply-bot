# ระบบผู้ช่วยงานพัสดุ กองทัพอากาศ (RTAF Supply Bot)

> แชทบอทตอบคำถามด้านงานพัสดุ สืบค้นระเบียบการจัดซื้อ และบริหารคลังพัสดุ  
> เข้าถึงได้ผ่าน URL ทันที ไม่ต้องติดตั้งในเครื่อง

**URL:** https://rtaf-supply.streamlit.app  
**จัดทำโดย:** พ.อ.อ.กนก คงสีทอง

---

## ภาพรวมการทำงาน

ผู้ใช้พิมพ์คำถามเป็นภาษาไทยในหน้าเว็บ ระบบค้นคำตอบจาก **ฐานความรู้** (เอกสารระเบียบที่ผู้ดูแลอัปโหลดไว้)
แล้วแสดงคำตอบพร้อม **เลขอ้างอิง** ที่กดดูชื่อไฟล์และข้อความต้นฉบับได้

```
ผู้ใช้ ──► หน้าเว็บ (Streamlit Cloud) ──► ฐานความรู้ (เอกสารระเบียบ)
                    │
                    └─ กุญแจเข้าระบบ (เก็บใน Secrets) ──► ต่ออายุการเข้าสู่ระบบเองอัตโนมัติ
```

ผู้ดูแลตั้งค่า **กุญแจเข้าระบบ** ครั้งเดียว หลังจากนั้นระบบต่ออายุการเข้าสู่ระบบเอง
ไม่ต้องล็อกอินซ้ำ ไม่ต้องรีเฟรชด้วยมือ และไม่ต้องเปิดคอมพิวเตอร์ทิ้งไว้

## เริ่มใช้งานจริง (สำหรับผู้ดูแล)

ทำตามลำดับนี้ ใช้เวลาประมาณ 10 นาที

### ขั้นที่ 1 — เตรียมค่า 2 อย่าง

| ค่า | ได้มาจาก |
|---|---|
| `NOTEBOOK_ID` | รหัสของฐานความรู้ อยู่ใน URL ของ Notebook (ส่วนที่ต่อจาก `/notebook/`) |
| `ADMIN_PASSWORD` | ตั้งเอง **ยาว 12 ตัวอักษรขึ้นไป ไม่ใช่เลขเรียงหรือคำที่เดาง่าย** (แอปเปิดสาธารณะ) |

และเตรียม **บัญชี Google เฉพาะกิจ** ที่เข้าถึงฐานความรู้ได้ (ไม่ใช้บัญชีส่วนตัวที่ผูกกับงานอื่น)

### ขั้นที่ 2 — ออกกุญแจเข้าระบบ (ทำครั้งเดียว บนคอมพิวเตอร์ที่มี Google Chrome)

```bash
pip install -r requirements-admin.txt
python setup_token.py
```

สคริปต์จะถามอีเมลบัญชีเฉพาะกิจ แล้ว **เปิด Chrome หน้าต่างชั่วคราว** ให้ทำตามนี้:
1. ล็อกอินบัญชี Google เฉพาะกิจ
2. กดปุ่ม **I agree** แล้ว **รอเฉย ๆ อย่าปิดหน้าต่าง**

สคริปต์จับกุญแจเองทั้งหมด ไม่ต้องคัดลอกอะไรด้วยมือ เมื่อเสร็จจะพิมพ์บรรทัดสำหรับวางใน Secrets
แล้วปิด Chrome และลบโปรไฟล์ชั่วคราวให้อัตโนมัติ

> **ห้ามแคปหน้าจอหรือส่งบรรทัดที่พิมพ์ออกมาให้ใคร** มันคือกุญแจของทั้งบัญชี Google

### ขั้นที่ 3 — วางใน Streamlit Secrets

เปิด Streamlit → **App settings → Secrets** แล้วใส่ค่าทั้ง 3 ตัว (วางบรรทัดกุญแจที่คัดลอกมาได้ทั้งบรรทัด):

```toml
NOTEBOOK_ID = "รหัสจากขั้นที่ 1"
ADMIN_PASSWORD = "รหัสผ่านที่ตั้งเอง"
NOTEBOOKLM_MASTER_TOKEN_JSON = '''วางบรรทัดที่ได้จาก setup_token.py'''
```

กด **Save changes** แล้ว **Reboot app**

> ⚠️ ระวังอย่าให้ `NOTEBOOK_ID` หายตอนวาง ถ้าขาด แอปจะขึ้น "ไม่พบ NOTEBOOK_ID" ใช้งานไม่ได้เลย
> ค่าของระบบเดิม (`GIST_ID`, `GITHUB_TOKEN`, `SESSION_ENC_KEY`) เก็บไว้เป็นตัวสำรองได้ หรือลบทิ้งเมื่อไม่ใช้แล้ว

### ขั้นที่ 4 — ทดสอบ

เปิดแอปแล้วถามคำถาม 1 ข้อ

| ผลที่เห็น | ความหมาย |
|---|---|
| ตอบได้ ไม่มีคำเตือนสีเหลือง | ✅ ใช้กุญแจเข้าระบบได้แล้ว |
| คำเตือน *"ตั้งค่า master token ไม่สำเร็จ — ใช้ session สำรองแทน"* | ค่าที่วางผิดหรือไม่ครบ ตรวจ Secrets ว่าวางครบทั้งบรรทัดและมี `'''` ปิดท้าย |
| ขึ้น "ไม่พบ NOTEBOOK_ID" | ไม่มี `NOTEBOOK_ID` ใน Secrets |
| ไม่เห็นเมนู 🔐 ผู้ดูแลระบบ / ใช้ฟังก์ชันผู้ดูแลไม่ได้ | ยังไม่ได้ตั้ง `ADMIN_PASSWORD` |

### ขั้นที่ 5 — ใช้งานต่อเนื่องแล้วค่อยปิดของเก่า

ใช้งานปกติ 1–5 วัน ถ้าไม่เจอหน้า **"Session Google หมดอายุ"** แสดงว่าระบบต่ออายุเองได้จริง
จึงปิดงานตั้งเวลารีเฟรชเดิมบนคอมพิวเตอร์ และเก็บกวาดระบบเดิมตามหัวข้อ [ระบบเดิม](#ระบบเดิม-gist--keep-alive)

## คุณสมบัติ

แอปมี 3 หน้า (เมนูแถบซ้าย)

### 💬 ถาม–ตอบ
- ถามเป็นภาษาไทย ได้คำตอบพร้อม **เลขอ้างอิง** กดหรือชี้ดูชื่อไฟล์ต้นฉบับและข้อความที่อ้างอิง (ไฮไลต์ในบริบทรอบข้าง)
- รายการ **แหล่งข้อมูลอ้างอิง** ใต้คำตอบ ใช้ได้บนมือถือ
- **คำถามต่อเนื่อง** — ปุ่มคำถามถัดไปที่ระบบแนะนำหลังตอบ
- บทสนทนาต่อเนื่องและ **แยกรายผู้ใช้** (ไม่ปนกับคนอื่น)
- **ส่งออกบทสนทนา** เป็นไฟล์ Markdown พร้อมแหล่งอ้างอิง และปุ่ม **เริ่มบทสนทนาใหม่**
- **คำเตือนใต้คำตอบ** ให้ตรวจกับระเบียบฉบับจริง พร้อมวันที่อัปเดตเอกสารล่าสุด
- **ปุ่ม 👍/👎** ใต้คำตอบล่าสุด — กด 👎 ระบบเก็บคำถามและคำตอบเป็นโน้ตในสมุดบันทึก (ผู้ดูแลเปิดดูได้ ไม่หายเมื่อรีบูตแอป)

### 📚 แหล่งข้อมูล
- รายการไฟล์ทั้งหมดในฐานความรู้ พร้อมชนิดไฟล์และจำนวนคำ
- **สรุป + คำสำคัญ** ของแต่ละไฟล์ ตอบเป็นภาษาเดียวกับเอกสารต้นฉบับ
- **ดูเนื้อหาเต็ม** ของไฟล์
- ผู้ดูแล: เพิ่มไฟล์ (PDF, Word, ข้อความ, Markdown, EPUB, เสียง, รูปภาพ), ลิงก์/YouTube, วางข้อความ และลบแหล่งข้อมูล (มีขั้นยืนยัน)

### 🎨 สื่อสรุป
สร้างและดาวน์โหลดสื่อจากแหล่งข้อมูลชุดเดียวกัน

| ชนิด | ไฟล์ที่ดาวน์โหลด |
|---|---|
| พอดแคสต์ (เจาะลึก / สรุปสั้น / วิพากษ์ / โต้วาที) | เสียง (มีตัวเล่นในหน้า) |
| รายงาน / คู่มือสรุป / บทความ | Markdown |
| สไลด์นำเสนอ | PDF หรือ PPTX |
| แบบทดสอบ, แฟลชการ์ด | JSON, Markdown, HTML |
| แผนผังความคิด | JSON (แสดงเป็นรายการซ้อนชั้นในหน้า) |
| ตารางข้อมูล | CSV |
| อินโฟกราฟิก | PNG (แสดงตัวอย่างในหน้า) |

ผู้ใช้ทั่วไปดาวน์โหลดสื่อที่มีอยู่ได้ ส่วนการ **สร้างใหม่** สำหรับผู้ดูแล (ใช้โควตา)

## สิทธิ์การใช้งาน

ระบบใช้บัญชี Google **บัญชีเดียวร่วมกัน** จึงแบ่งสิทธิ์เพื่อไม่ให้ฐานความรู้ถูกแก้ไขหรือโควตาหมด

| ผู้ใช้ทั่วไป | ผู้ดูแล (ใส่ `ADMIN_PASSWORD` ที่แถบซ้าย → 🔐 ผู้ดูแลระบบ) |
|---|---|
| ถาม–ตอบ, ส่งออกบทสนทนา, ดูสรุป/เนื้อหาไฟล์, ดาวน์โหลดสื่อที่มีอยู่ | เพิ่ม/ลบแหล่งข้อมูล, สร้างสื่อใหม่, บันทึกบทสนทนาเป็นโน้ตในฐานความรู้, ตรวจโควตา |

- ถ้าไม่ตั้ง `ADMIN_PASSWORD` ฟังก์ชันผู้ดูแลจะ **ปิดทั้งหมด**
- จำกัดการใส่รหัสผิด 5 ครั้งต่อ session (นับใหม่เมื่อรีเฟรชหน้า) จึงต้องตั้งรหัสให้ยาวและเดายาก

## Secrets ทั้งหมด

| ตัวแปร | จำเป็น | ความหมาย |
|---|---|---|
| `NOTEBOOK_ID` | ✅ | รหัสฐานความรู้ |
| `NOTEBOOKLM_MASTER_TOKEN_JSON` | ✅ แนะนำ | กุญแจเข้าระบบ ได้จาก `setup_token.py` |
| `ADMIN_PASSWORD` | แนะนำ | รหัสผู้ดูแล (ถ้าไม่ตั้ง ฟังก์ชันผู้ดูแลถูกปิด) |
| `GIST_ID`, `GITHUB_TOKEN`, `SESSION_ENC_KEY` | ทางเลือก (ระบบเดิม) | ดึงการเข้าสู่ระบบจาก Gist เป็นตัวสำรอง |

ลำดับที่แอปใช้เข้าสู่ระบบ: กุญแจเข้าระบบ → Gist (ระบบเดิม) → `NOTEBOOKLM_AUTH_JSON`
เมื่อมีกุญแจเข้าระบบ แอปจะไม่ใช้ `NOTEBOOKLM_AUTH_JSON`

## ความปลอดภัย

| เรื่อง | รายละเอียด |
|---|---|
| ค่าลับ | เก็บใน Streamlit Secrets เท่านั้น **ห้าม commit** (`master_token.json` และ `storage_state.json` อยู่ใน `.gitignore`) |
| กุญแจเข้าระบบ | เป็น credential ของ **ทั้งบัญชี Google** ไม่หมดอายุเอง และเปลี่ยนรหัสผ่านก็ไม่ทำให้ใช้ไม่ได้ |
| บัญชี | ใช้บัญชีเฉพาะกิจ ไม่ผูกกับงานอื่น แชร์ฐานความรู้ให้บัญชีนั้นเท่านั้น |
| ถ้าสงสัยว่ารั่ว | Google Account → Security → Your devices → ลบอุปกรณ์ที่ไม่รู้จัก แล้วรัน `python setup_token.py` ออกกุญแจใหม่ วางทับใน Secrets |
| ภาพหน้าจอ/แชท | อย่าส่งหรือแคปหน้าจอที่มีกุญแจ รหัสผ่าน หรือ Secrets |
| รหัสผู้ดูแล | ตั้งให้ยาวและเดายาก เพราะแอปเปิดสาธารณะ |

## โครงสร้างไฟล์

```
rtaf-supply-bot/
├── app.py                    # หน้าเว็บ Streamlit (ถาม–ตอบ / แหล่งข้อมูล / สื่อสรุป)
├── features.py               # ฟังก์ชันเรียกฐานความรู้ (ไม่พึ่ง streamlit ทดสอบแยกได้)
├── citations.py              # เลขอ้างอิง + การ์ดแหล่งข้อมูล
├── theme.py                  # หน้าตา (สีน้ำเงิน–ทอง แบนเนอร์ ปุ่ม ฟองแชต)
├── assets/logo.png           # โลโก้ในแบนเนอร์และไอคอนแท็บ
├── .streamlit/config.toml    # สีหลักของธีม
├── auth_setup.py             # ติดตั้งกุญแจเข้าระบบฝั่งเซิร์ฟเวอร์
├── setup_token.py            # ผู้ดูแลรันครั้งเดียว: ออกกุญแจด้วยคำสั่งเดียว
├── export_master_token.py    # พิมพ์บรรทัดที่ต้องวางใน Secrets (setup_token.py เรียกให้เอง)
├── requirements.txt          # แพ็กเกจฝั่งเซิร์ฟเวอร์
├── requirements-admin.txt    # แพ็กเกจฝั่งเครื่องผู้ดูแล (ใช้กับ setup_token.py)
├── eval/run_eval.py          # รันชุดคำถามทดสอบความแม่น (เครื่องผู้ดูแล)
├── scripts/wake_app.py       # ปลุกแอปที่หลับ (ใช้โดย GitHub Actions)
├── .github/workflows/wake.yml
└── tests/                    # ทดสอบฟังก์ชันที่ไม่ต้องใช้เครือข่าย
```

รันทดสอบ: `python tests/test_features.py`, `python tests/test_auth_setup.py`, `python tests/test_setup_token.py`, `python tests/test_extras.py`

### ปรับหน้าตา

- **เปลี่ยนโลโก้:** วางไฟล์ภาพใหม่ชื่อ `assets/logo.png` (สี่เหลี่ยมจัตุรัส ประมาณ 200×200 px) ทับของเดิม ไม่ต้องแก้โค้ด ถ้าไม่มีไฟล์จะใช้ไอคอนเครื่องบิน
- **เปลี่ยนสี/ชื่อหัวเว็บ:** สีอยู่ที่ต้นไฟล์ `theme.py` (`NAVY`, `BLUE`, `GOLD`) และ `.streamlit/config.toml` ส่วนข้อความแบนเนอร์อยู่ใน `HERO_HTML` ท้ายไฟล์ `theme.py`

### ดูความเห็นจากผู้ใช้ (👎)

เมื่อผู้ใช้กด 👎 ระบบสร้างโน้ตชื่อ "ข้อสังเกต 👎 ..." ในสมุดบันทึก ผู้ดูแลเปิดดูในหน้าสมุดบันทึกของ Google ได้
ใช้ปรับเอกสารต้นทางหรือเพิ่มคำถามลงชุดทดสอบ (กด 👍 บันทึกเฉพาะใน Logs ของ Streamlit: Manage app → Logs)

### ชุดคำถามทดสอบความแม่น

1. คัดลอก `eval/questions.example.json` เป็น `eval/questions.json` แล้วใส่คำถามจริง พร้อมคำ/ตัวเลขที่คำตอบต้องมี (`expect_any`, `expect_all`) จากระเบียบฉบับจริง
2. รันบนเครื่องผู้ดูแล: `python eval/run_eval.py --questions eval/questions.json --notebook รหัสสมุดบันทึก`
   (ถ้าออกกุญแจแบบมีโปรไฟล์ ใส่ `--profile ชื่อ`) ได้ไฟล์รายงาน `eval-report.md`
3. รันซ้ำทุกครั้งที่เพิ่ม/แก้เอกสาร เพื่อดูว่าคำตอบเดิมยังถูกอยู่

### ป้องกันแอปหลับ

`.github/workflows/wake.yml` เปิดหน้าเว็บด้วยเบราว์เซอร์ทุก 6 ชั่วโมงและกดปุ่มปลุกให้ ใช้ได้เลยหลัง merge
(ถ้าเปลี่ยน URL แอป ตั้ง Variable `APP_URL` ใน Settings → Secrets and variables → Actions → Variables)
GitHub จะหยุดงานตั้งเวลาถ้า repo ไม่มีกิจกรรม 60 วัน ให้กด Run workflow เพื่อเปิดใหม่

## ข้อมูลทางเทคนิคสำหรับผู้พัฒนา

ฐานความรู้ของระบบคือ Google NotebookLM (ปัจจุบันเรียก Gemini Notebook) เชื่อมต่อผ่านไลบรารี
[notebooklm-py](https://github.com/teng-lin/notebooklm-py) ซึ่ง **ไม่เป็นทางการ** ใช้ API ภายในของ Google
ผู้ดูแลทั่วไปไม่ต้องรู้รายละเอียดนี้ในการใช้งาน (`setup_token.py` เรียกให้เอง) แต่ควรทราบข้อจำกัด:

- Google อาจเปลี่ยนระบบภายในโดยไม่แจ้ง ทำให้แอปใช้ไม่ได้ชั่วคราว
- มีลิมิตจำนวนแหล่งข้อมูลและโควตาการสร้างสื่อตามระดับบัญชี Google
- ใช้บัญชีเดียวร่วมกัน ผู้ใช้หลายคนพร้อมกันใช้โควตาร่วมกัน

## ระบบเดิม (Gist + Keep-Alive) — ยกเลิกแล้ว

ไฟล์ของระบบเดิม (`cloud_keepalive.py`, `refresh_session.py/.bat`, `generate_key.py`, `.github/workflows/keepalive.yml`) ถูกลบออกแล้ว
ถ้ายังไม่ได้ทำ ให้เก็บกวาดฝั่งผู้ดูแลดังนี้:
1. เพิกถอน `GITHUB_TOKEN` ที่เคยใช้ และลบ Gist
2. ลบ `GIST_ID`, `GITHUB_TOKEN`, `SESSION_ENC_KEY` ออกจาก Streamlit Secrets และ Secrets ของ GitHub Actions
