ระบบนี้ใช้ NotebookLM เป็น AI ตอบคำถาม ผ่าน Streamlit Cloud
เมื่อติดตั้งเสร็จ ผู้ใช้ทุกคนเข้าใช้งานผ่าน URL ได้ทันที
โดยไม่ต้องติดตั้งอะไรในเครื่องตัวเอง

★ เวอร์ชัน 2.0 นี้ใช้ GitHub Actions รัน Keep-Alive อัตโนมัติ
  ทุก 5 นาที บน Cloud — ไม่ต้องเปิดเครื่องคอมไว้ตลอด ★

──────────────────────────────────────────────────────────────────
ส่วนที่ 1 : สิ่งที่ต้องมีก่อน
──────────────────────────────────────────────────────────────────

[ ] Python 3.10+ ติดตั้งในเครื่อง (สำหรับ login ครั้งแรกเท่านั้น)
[ ] บัญชี GitHub (github.com)
[ ] บัญชี Streamlit Cloud (streamlit.io)
[ ] บัญชี Google ที่มีสิทธิ์เข้า NotebookLM
[ ] NotebookLM Notebook ที่อัปโหลดเอกสารพัสดุไว้แล้ว
    → จด NOTEBOOK_ID ไว้ (ได้จาก URL ของ Notebook)
    → ตัวอย่าง URL: notebook.google.com/notebook/[NOTEBOOK_ID]

──────────────────────────────────────────────────────────────────
ส่วนที่ 2 : ติดตั้ง notebooklm-py ในเครื่อง
──────────────────────────────────────────────────────────────────

เปิด PowerShell หรือ Command Prompt แล้วรัน:

  pip install notebooklm-py[browser] cryptography requests
  playwright install chromium

จากนั้น login Google ครั้งแรก:

  python -m notebooklm login

  → browser จะเปิดขึ้น → login บัญชี Google
  → รอขึ้นว่า "Authentication saved to: ...storage_state.json"

หมายเหตุ: ขั้นตอนนี้ทำแค่ครั้งแรกเท่านั้น
          หลังจากนี้ GitHub Actions จะดูแล session ให้อัตโนมัติ

──────────────────────────────────────────────────────────────────
ส่วนที่ 3 : สร้าง GitHub Repository (Public)
──────────────────────────────────────────────────────────────────

1. เข้า github.com → New repository
2. ตั้งชื่อ เช่น "rtaf-supply-bot"
3. เลือก Public ← สำคัญ! ต้องเป็น Public เพื่อใช้ Actions ฟรีไม่จำกัด
4. สร้างไฟล์ในเครื่อง แล้ว push ขึ้น GitHub

   ไฟล์ที่ต้องมีใน Repository:
   ├── app.py                            ← โค้ดหลักของแอป
   ├── requirements.txt                  ← รายการ package
   ├── cloud_keepalive.py                ← สคริปต์ Keep-Alive บน Cloud
   ├── refresh_session.py                ← login Google (ใช้ในเครื่อง)
   ├── refresh_session.bat               ← เปิด refresh_session ง่ายๆ
   └── .github/
       └── workflows/
           └── keepalive.yml             ← GitHub Actions schedule

ส่วนที่ 4 : เนื้อหาไฟล์ requirements.txt
──────────────────────────────────────────────────────────────────

notebooklm-py[browser]

──────────────────────────────────────────────────────────────────
ส่วนที่ 5 : เนื้อหาไฟล์ app.py
──────────────────────────────────────────────────────────────────

(ดูไฟล์ app.py ที่แนบมาพร้อมคู่มือนี้)

จุดสำคัญใน app.py:
- ข้อมูลสำคัญทั้งหมด (NOTEBOOK_ID, GIST_ID ฯลฯ) ถูกซ่อนไว้
  ใน Streamlit Secrets ทั้งหมด ไม่มีในโค้ด
- ระบบดึง session จาก GitHub Gist อัตโนมัติ
- มีหน้า "Session หมดอายุ" พร้อมคำแนะนำสำหรับผู้ดูแล

──────────────────────────────────────────────────────────────────
ส่วนที่ 6 : สร้าง GitHub Gist (เก็บ session เข้ารหัส)
──────────────────────────────────────────────────────────────────

1. เข้า gist.github.com
2. กรอก:
   - Gist description: RTAF session storage (หรืออะไรก็ได้)
   - Filename: session.enc   ← ต้องชื่อนี้เท่านั้น!
   - Content: placeholder    ← ใส่คำนี้ไปก่อน
3. กด "Create secret gist"   ← ต้องเลือก secret ไม่ใช่ public
4. copy GIST_ID จาก URL:
   gist.github.com/username/[GIST_ID ตรงนี้]

──────────────────────────────────────────────────────────────────
ส่วนที่ 7 : สร้าง GitHub Personal Access Token
──────────────────────────────────────────────────────────────────

1. เข้า github.com → Settings → Developer settings
2. Personal access tokens → Tokens (classic)
3. กด "Generate new token (classic)"
4. ตั้งชื่อ: RTAF-Bot
5. Expiration: No expiration
6. ติ๊กแค่ "gist" เท่านั้น! ห้ามติ๊กอื่น
7. กด Generate token → copy ทันที (แสดงแค่ครั้งเดียว!)

⚠️ ห้ามเก็บ token ไว้ใน code หรือ commit ขึ้น GitHub เด็ดขาด!

──────────────────────────────────────────────────────────────────
ส่วนที่ 8 : สร้าง Encryption Key
──────────────────────────────────────────────────────────────────

รันไฟล์ generate_key.py ในเครื่อง:

  python generate_key.py

→ copy key ที่แสดงออกมา เก็บไว้ให้ดี อย่าให้ใครรู้!

──────────────────────────────────────────────────────────────────
ส่วนที่ 9 : ตั้งค่า Streamlit Cloud Secrets
──────────────────────────────────────────────────────────────────

1. เข้า streamlit.io → New app
2. เชื่อมต่อ GitHub Repository ที่สร้างไว้
3. Deploy แอป
4. เข้า App settings → Secrets
5. ใส่ค่าดังนี้ครบทุกบรรทัด:

   NOTEBOOK_ID     = "ใส่ NOTEBOOK_ID จาก URL ของ NotebookLM"
   GIST_ID         = "ใส่ GIST_ID จากส่วนที่ 6"
   GITHUB_TOKEN    = "ghp_ใส่ token จากส่วนที่ 7"
   SESSION_ENC_KEY = "ใส่ key จากส่วนที่ 8"

6. กด Save → Streamlit จะ redeploy อัตโนมัติ

หมายเหตุ: ข้อมูลใน Secrets จะถูกเข้ารหัสและซ่อนจากผู้ใช้ทั่วไป
          แม้แต่ผู้ที่เห็น code ใน GitHub ก็ไม่สามารถดูได้

──────────────────────────────────────────────────────────────────
ส่วนที่ 10 : ตั้งค่า GitHub Actions Secrets
──────────────────────────────────────────────────────────────────

GitHub Actions ต้องการ secrets แยกต่างหากจาก Streamlit
(ต้องตั้งค่าทั้ง 2 ที่)

1. ไปที่ Repository → Settings → Secrets and variables → Actions
2. กด "New repository secret" แล้วเพิ่มทีละตัว 4 ตัว:

   ┌─────────────────┬────────────────────────────────────────┐
   │ Name            │ Secret (ค่า)                            │
   ├─────────────────┼────────────────────────────────────────┤
   │ GIST_TOKEN      │ ghp_token จากส่วนที่ 7                     │
   │ GIST_ID         │ GIST_ID จากส่วนที่ 6                       │
   │ ENCRYPTION_KEY  │ key จากส่วนที่ 8 (ตัวเดียวกับ Streamlit)       │
   │ NOTEBOOK_ID     │ NOTEBOOK_ID จาก NotebookLM URL          │
   └─────────────────┴────────────────────────────────────────┘

⚠️ ช่อง Name ใส่แค่ชื่อ เช่น GIST_TOKEN
   ช่อง Secret ใส่แค่ค่า เช่น ghp_xxx... (ไม่มีชื่อนำหน้า)
   ต้องสร้างทีละตัว ไม่ใช่ใส่รวมกันในตัวเดียว

──────────────────────────────────────────────────────────────────
ส่วนที่ 11 : เพิ่มไฟล์ GitHub Actions เข้า Repository
──────────────────────────────────────────────────────────────────

ไฟล์ที่ 1 : cloud_keepalive.py
→ ไปที่ Repository → Add file → Create new file
→ ชื่อ: cloud_keepalive.py
→ วางโค้ดจากไฟล์ cloud_keepalive.py ที่แนบมา

ไฟล์ที่ 2 : .github/workflows/keepalive.yml
→ Add file → Create new file
→ ชื่อ: .github/workflows/keepalive.yml
   (พิมพ์เต็มแบบนี้เลย GitHub จะสร้าง folder ให้อัตโนมัติ)
→ วางโค้ดจากไฟล์ keepalive.yml ที่แนบมา
→ Commit changes

──────────────────────────────────────────────────────────────────
ส่วนที่ 12 : รันครั้งแรก (อัปโหลด session ขึ้น Gist)
──────────────────────────────────────────────────────────────────

ขั้นที่ 1 : อัปโหลด session ขึ้น Gist ครั้งแรก
  double-click refresh_session.bat
  → browser เปิด → login บัญชี Google
  → รอขึ้นว่า "✅ สำเร็จ! แอปจะดึง session ใหม่อัตโนมัติ"
  → กด Enter เพื่อปิด

ขั้นที่ 2 : ทดสอบ GitHub Actions
  ไปที่ Repository → Actions → NotebookLM Keep-Alive
  → กด "Run workflow" → รอ 1-2 นาที
  → ถ้าเห็น ✅ สีเขียว = พร้อมใช้งาน

ขั้นที่ 3 : ทดสอบแอป
  เข้า https://rtaf-supply.streamlit.app/
  → ทดสอบพิมพ์คำถาม

──────────────────────────────────────────────────────────────────
ส่วนที่ 13 : การทำงานปกติของระบบ (หลังติดตั้งเสร็จ)
──────────────────────────────────────────────────────────────────

  GitHub Actions (Cloud — ไม่ต้องเปิดเครื่อง)
      ↓
  ทุก 5 นาที → cloud_keepalive.py ทำงาน:
    • ดึง session จาก GitHub Gist
    • Ping NotebookLM → ต่ออายุ Google session
    • อัปโหลด session ที่อัปเดตกลับ Gist
      ↓
  Streamlit Cloud ดึง session จาก Gist
      ↓
  ผู้ใช้ทุกคนใช้งานได้ปกติ ✅

  ★ ระบบทำงาน 24 ชั่วโมง 7 วัน โดยไม่ต้องเปิดคอม ★

──────────────────────────────────────────────────────────────────
ส่วนที่ 14 : การบำรุงรักษา
──────────────────────────────────────────────────────────────────

   สถานการณ์              │    สิ่งที่ต้องทำ
────────────────────────┼───────────────────────────────────
ปิด/เปิดเครื่องใหม่        		│ ไม่ต้องทำอะไร (GitHub Actions ดูแล)
ผู้ใช้ใช้แอปปกติ           	│ ไม่ต้องทำอะไร
แอปขึ้น "Session หมดอายุ"  	│ double-click refresh_session.bat
  (หายากมาก เพราะ system  │ → login Google
   ping ทุก 5 นาที)       │ → กดปุ่มรีเฟรชในแอป
GitHub Actions หยุดทำงาน  │ ตรวจสอบ Actions tab ใน GitHub
Token หมดอายุหรือถูกยกเลิก 	│ สร้าง token ใหม่ → อัปเดต Secrets

──────────────────────────────────────────────────────────────────
ส่วนที่ 15 : การตรวจสอบสถานะระบบ
──────────────────────────────────────────────────────────────────

ตรวจสอบผ่าน GitHub Actions:
1. ไปที่ Repository → Actions
2. เลือก "NotebookLM Keep-Alive"
3. ดู run ล่าสุด:
   ✅ สีเขียว = ทำงานปกติ
   ❌ สีแดง   = มีปัญหา → คลิกดู log แล้วแก้ไข

ความถี่การรัน:
- Schedule อัตโนมัติ: ทุก 5 นาที
- รันมือ: Actions → Run workflow (ใช้ทดสอบ)
